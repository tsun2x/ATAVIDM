### Objective

Implement the authorized three-fold plan: browse reports by video with scoped pagination and export limits; make pickup passenger evidence fail closed when lower-body visibility is unknown; add bounded local evaluation tools for pickup crop and motorcycle-detail model comparisons.

### Detailed Changes

The Reports preview uses a bounded page query and returns full filtered counts separately. The route validates pagination and filters and enforces account scope on the server. The generation cap is checked before file/history creation. Pickup inference requires an explicit local checkpoint, output path, and finite time interval of at most 120 seconds; class IDs are validated and crop detections are mapped back to source coordinates. The comparison tool checks an explicit test split and matching three- or four-class roster, evaluates checkpoints sequentially, and reports per-class results with test instance counts. Neither evaluation tool changes designated application weights or infers legal outcomes.
