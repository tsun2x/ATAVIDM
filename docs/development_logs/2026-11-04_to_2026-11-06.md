## 2026-11-05 16:26 — Live camera scene annotation

### Objective and summary

Enable an administrator to draw and save scene annotations for an active CCTV camera using the existing annotation editor. A frozen raw camera frame provides the reference image; saving updates that camera and reconnects its stream.

### Files changed

- `core/live_stream.py` retains a raw JPEG snapshot, refreshed at most once per second.
- `app.py` exposes the authenticated, non-cached camera annotation frame endpoint.
- `static/js/live_monitor.js` opens the editor for the selected camera and reconnects after save.
- `static/js/upload.js` reuses the scene editor for camera annotation and saves through the existing camera update API.
- `templates/live_monitor.html` warns that moving a camera invalidates its scene geometry.
- `tests/test_live_camera_annotation.py` tests snapshot access, missing frames, permissions, scene persistence, and worker stop on save.
- `docs/development_logs/2026-11-04_to_2026-11-06.md` records the work.

### Technical and API impact

The new `GET /api/cameras/<id>/annotation-frame` endpoint requires login and returns 409 until a frame exists. Camera changes remain admin-only and use the existing `PUT /api/cameras/<id>` endpoint and existing annotation schema; no database migration or dependency change is required. Each active worker holds an extra JPEG and encodes at most one raw snapshot per second. A save stops the previous worker and the browser requests a fresh stream.

### Verification and limitations

- `tests/test_live_camera_annotation.py`: 2 passed with a test bootstrap password.
- JavaScript syntax checks and `git diff --check` passed.
- Existing `tests/test_annotation_editor_gate4.py`: 2 passed, 1 failed with `Video not found` in the isolated test environment.
- The full suite was started but interrupted after early progress; it was not completed.
- Real-camera browser save/reconnect and geometry behavior were not manually verified. The application must be restarted to load the changes. Physical camera movement invalidates saved geometry.

### Project progress and next steps

Live camera detection and the video scene editor exist in code; live camera scene editing now shares that editor. Restart TAVIDM and verify drawing, saving, reconnecting, and scene alignment with the real camera. Broader system validation and unresolved regression failures remain.
