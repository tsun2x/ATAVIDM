## 2026-11-16 11:25 — Compact support diagnostics export

Added an administrator-only JSON download in Settings. It combines a bounded in-memory trail of selected request outcomes with up to 50 persisted processing-run summaries, class counts, rule capability flags, and motorcycle/pickup candidate counts. The trail retains up to 500 entries and resets on process restart. The export excludes media, filenames, raw errors, request parameters and credentials; it is not an accuracy measurement or a full audit trail.

Files: `core/support_diagnostics.py`, `app.py`, `database/db.py`, `database/sqlite_adapter.py`, `templates/settings.html`, and `tests/test_support_diagnostics.py`. No schema or dependency changes.

Focused verification: diagnostics, camera annotation and account scoping tests passed (15 tests); diagnostics tests passed again after the initial test enhancement (3 tests). Python compile checks passed. The full suite was interrupted after reaching 7% with failures in existing annotation-editor and case-policy tests; it did not finish and no full-suite pass is claimed. Real browser and CCTV testing were not performed.

## 2026-11-16 11:57 — Validate upload recording dates and examine reported results
