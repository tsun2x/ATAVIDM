## 2026-08-31 18:22 — Build provisional pickup candidate dataset

### Objective

Create and run a fail-closed cleaner that preserves manual pickup-review decisions, culls objective structural defects, provisionally accepts undecided structurally valid candidates, produces a source-balanced audit sample and complete reports, and leaves raw sources, quarantine data, pre-screening output, and benchmark splits unchanged. The output is explicitly marked unapproved for training and contains full audit, snapshot, inventory, and source-balanced sampling reports.

---

### Detailed Changes

- Validates the candidate manifest, queue schema, unique filenames, manual-decision linkage, stored hashes, readable image files, label structure, class IDs, finite normalized coordinates, positive box dimensions, image-bound containment, and presence of at least one pickup annotation.
- Applies existing `keep`, `reject`, and `uncertain` decisions without converting provisional decisions into manual approvals.
- Copies only accepted image/label pairs into the derived training split.
- Copies benchmark validation and test trees without modification.

---

### Technical Explanation

The cleaner uses deterministic CSV processing, SHA-256 provenance checks, Pillow image verification, strict YOLO annotation validation, and `shutil.copy2` for independent derived files. Manual decision hashes must match the queue hash or the entire run fails before output creation. The balanced audit sample ranks accepted rows deterministically by a salted image hash and takes an equal requested count from each source.

---

### Code Impact

This adds an offline dataset-preparation utility and tests only. It does not modify inference, YOLOv8m/ByteTrack processing, rules, Flask endpoints, database schemas, or existing datasets.
