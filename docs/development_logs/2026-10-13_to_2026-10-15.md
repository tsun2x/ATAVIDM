## 2026-10-13 10:41 — Upload recording time and annotation help

### Objective

Make footage recording time easier to enter during upload and make the annotation guides accessible from the annotation workflow.

### Summary

Split the optional upload timestamp into separate date and time inputs, retaining the existing `recorded_at` API field. Added an authenticated Annotation Help page with tabs for the general and overlap annotation guides, linked from the annotation wizard. The guide documents are served through a fixed allowlist, and the HTML guides run inside sandboxed frames.

The Annotation Help page presents the three guide sources, while a route allowlist limits which guide files can be served.
