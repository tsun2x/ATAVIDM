### Technical Explanation

Set membership is O(1) per frame so a 10-minute episode does not do ~n² spill scans. Durable evidence is a commit-point: either a complete sequence (and clip) plus `.finalized`, or the open episode and spool remain for retry/abort. The memory spy holds references to every yielded `BufferedFrame`; if finalize materialized the whole spool, live JPEG bytes would scale with n. Clearing `bf.jpeg` after each write keeps the spy peak near one frame.
