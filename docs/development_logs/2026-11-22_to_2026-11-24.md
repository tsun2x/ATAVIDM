## Overview

Motorcycle Detail Review supports multiple proposed violations for the same observation.

## Development Entries

### 2026-11-22 12:55 — Submit multiple motorcycle violations for review

- `static/js/motorcycle_detail_review.js` lets reviewers select multiple violation checkboxes. No Violation clears all violation checkboxes. Selecting a violation clears No Violation.
- `app.py` validates the full selection and queues one pending review per proposed violation in a single transaction. Existing pending reviews for the same candidate and rule are reused. No Violation closes all pending linked items through the existing decision service. Direct case confirmation still accepts a single choice.
- `database/adapter_base.py`, `database/db.py`, and `database/sqlite_adapter.py` expose all review rows linked to a detail candidate. The SQLite schema and existing single-choice API remain compatible.
- `tests/test_motorcycle_detail_api.py` and `tests/js/test_motorcycle_detail_helpers.cjs` cover multiple selections, exclusivity, pending review deduplication, and rollback if one proposal fails.

#### Verification

The original API returned HTTP 400 for a valid multi-choice request. Headless Chrome verified selecting two violations, switching to No Violation, then switching back. The broader motorcycle API and scan suite reported 80 passes and two known direct-confirmation fixture failures.
