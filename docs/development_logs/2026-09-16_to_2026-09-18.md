## 2026-09-16 00:44 — Build external weak-class review supplement

### Objective

Create a provenance-preserving, image-only Roboflow review package from audited external bicycle, bus, van, and helmet datasets without modifying the frozen 848-image V9 baseline or authorizing training.

---

### Summary

Added a fail-closed builder and behavioral tests for selecting external weak-class review candidates. The generated package contains 500 unique images: 200 bicycle, 100 bus, 100 van, and 100 helmet candidates requiring manual semantic review. External annotations are retained only as local provenance and are not included in the upload ZIP.

---

### Files Modified

#### Created

- `build_v9_external_review_supplement.py`
  - Deterministic, duplicate-aware external review-package builder.
- `tests/test_build_v9_external_review_supplement.py`
  - Covers image-only output, unmapped helmet candidates, and polygon-row rejection.
- `dataset/review_packages/roboflow_v9_external_500_20260916/`
  - Generated upload ZIP, source manifest, review queue, instructions, class roster, summary, and visual-QA contact sheets.
- `docs/development_logs/2026-09-16_to_2026-09-18.md`
  - Active segmented development log.

---

### Detailed Changes

- Parses YOLO archives and validates CRC, class IDs, five-field detection rows, image-label pairing, and image readability.
- Excludes exact baseline duplicates and rejects exact or perceptually near-duplicate selections.
- Prevents automatic conversion of external `invalid` helmet labels to `helmet_nut_shell`.
- Produces an image-only Roboflow ZIP requiring complete re-annotation against the frozen 15-class object roster.
- Preserves source archive paths, hashes, splits, labels, licenses, and candidate-selection purpose in local documentation.

---

### Technical Explanation

Selection uses SHA-256 for exact identity and 64-bit difference hashes for bounded near-duplicate rejection. Inputs and the 848-image baseline remain immutable; all outputs are versioned derivatives. Helmet candidates have an empty canonical candidate-class list and `semantic_mapping_authorized: false`.

---

### Code Impact

Adds an offline dataset-preparation tool only. Runtime detection, tracking, rules, APIs, and model configuration are unchanged.

---

### Database Changes

None.

---

### API Changes

None.

---

### UI / UX Changes

None.

---

### Dependencies

No new packages. Uses existing Python, OpenCV, NumPy, and standard-library modules.

---

### Testing

- Recorded red state: focused tests failed because the builder did not exist.
- Green verification: `python -m pytest tests\test_build_v9_external_review_supplement.py -q` completed with 2 passed.
- Package verification confirmed 500 ZIP entries, 500 unique hashes, valid CRC, image-only contents, no unsafe helmet mappings, and `training_authorized: false`.
- Visual spot checks were generated for all selection groups.

---

### Performance Notes

Archive inputs are read without extraction. Candidate image hashing and decoding are bounded by the source archives and intended for offline preparation.

---

### Known Limitations

The candidate package remains pending human visual review. Bicycle samples include rotated and non-CCTV imagery; bus and van samples are largely catalog or street photographs. Helmet candidates come from a single CCTV viewpoint and require exact semantic review.

---

### Risks

Uploading without visual curation or complete re-annotation could introduce domain mismatch, partial-label false negatives, or incorrect helmet semantics.

---

### Next Recommended Steps

Perform owner visual review, remove unsuitable candidates, replace rejected images while preserving quotas, fully annotate accepted images, validate the Roboflow export, and request separate merge/training authorization.
