How to think about overlapping annotations

Linked combination

Required objects must be assigned to the same lane when the evaluator matches lane IDs. Drawing them next to each other is not enough.

Two restrictions, same area

Only overlap distinct zone polygons when both real restrictions apply. TAVIDM may emit separate candidates; reviewers decide each independently.

Not fixed by another shape

Helmet, mirror visibility, and cargo-passenger checks need object/evidence support. Extra zones do not make missing visual evidence appear.
