A reliable setup, step by step

1. Match the real scene

Use the correct fixed-camera view. Trace road edges and painted lines as seen in the video, not around vehicles. If the camera moved or the clip was cropped, check or redraw the geometry.

2. Draw areas and lines correctly

Areas need at least three points; lines and arrows need two. Follow perspective, keep polygons tidy, and use New object for a separate shape.

3. Link related items

Where shown, choose Apply to lane. For No Entry, the sign, threshold, and allowed flow arrow must refer to the same lane.

4. Confirm meaning before saving

Use a real known restriction. For markings, choose the actual paint type and prohibited approach side; “both” means either direction can be flagged.

5. Save and inspect

Save for this video or a same-camera template. Reopen the drawing and check lane links, endpoints, polygon edges, and arrow direction.

6. Reprocess to test

Annotation edits do not change old results. Process a new run and compare events with the clip; treat uncertain evidence as review, not a confirmed violation.

Some checks need visual evidence

Helmet, mirror visibility, rider count, and cargo-passenger checks are not fixed by drawing another zone. Check each rule’s evidence requirements; some evidence remains review-only or unavailable.
